Análise de Phishing com Kali Linux

Sobre o projeto

Projeto desenvolvido como parte do desafio de Cibersegurança da Digital Innovation One (DIO).

O objetivo é estudar técnicas de Engenharia Social e compreeender como ataques de Phishing utilizam páginas fraudulentas para enganar usuários.

Objetivos

Compreender o funcionamento do Phishing
Conhecer a ferramenta Social-Engineer Toolkit (SEToolkit).
Estudar os ricos de páginas falsas de autenticação.
Conhecer técnicas de prevenção e proteção digital

Ferramentas utilizadas

Kali Linux
Social-Engineer Toolkit (SEToolkit)
Git
GitHub

Ambiente de Laboratório

A demonstração será realizada em ambiente controlado, utilizando páginas fictícas e credenciais de teste.

Não serão utilizadas contas reais, senhas pessoais ou serviços de terceiros para captura de informações.

Conceitos estudados

Engenharia Social

Técnica que explora o comportamento humano para obter informações ou induzir ações.

Phishing

Ataque que utiliza mensagens ou páginas fraudulentas para tentar obter informações confidenciais.

SEToolkit

Ferramenta de segurança utilizada para estudar e demonstrar técnicas de Engenharia Socil em ambientes autorizados.

Medidas de prevenção

Conferir o endereço dos sito
Evitar links suspeitos
Utilizar autenticação multifator
Não compartilhar senhas
Utilizar gerenciadores de senhas

Conclusão 

O desafio permitiu estudar os conceitos de Engenharia Social e Phishing, compreender os ricos associados a páginas fraudulentas e conhecer ferramentas utilizadas em estudos de segurança da informação

Projeto educacional desenvolvido para a DIO.
